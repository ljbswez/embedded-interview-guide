# 嵌入式软件面试宝典

一套可离线使用的中文嵌入式软件面试复习资料，覆盖 MCU / RTOS 和嵌入式 Linux。包含 15 个专题、120 道主问题、分章 Markdown 讲义，以及 8 个可独立编译运行的 C99 练习。

## 开始使用

用现代 Chrome 或 Edge 打开 [`index.html`](index.html)；Windows 下也可以双击 `开始学习.cmd`。网页可搜索题目、按方向筛选、记录笔记与掌握度，并导入或导出学习进度。无需安装依赖或联网；引用的外部资料链接需联网访问。

学习进度保存在当前浏览器的本地存储中。换设备前，请在网页中使用“备份学习进度”导出 JSON；备份可能包含个人笔记，请勿提交到仓库。

## 目录

| 路径 | 内容 |
| --- | --- |
| [`01_分章讲义/`](01_分章讲义/) | 15 份可独立阅读的 Markdown 讲义。 |
| [`02_面试准备/`](02_面试准备/) | 复习计划、项目复盘模板、练习说明与官方资料索引。 |
| [`03_代码练习/`](03_代码练习/) | 8 个包含 `assert` 测试的独立 C99 程序。 |
| [`assets/`](assets/) | 离线网页的样式、逻辑与题库数据。 |

编译单个练习示例：

```sh
cc -std=c99 -Wall -Wextra -Werror 03_代码练习/01_ring.c -o ../ring_test
../ring_test
```

每个练习都有自己的 `main`，请分别编译。更多说明见 [`目录与使用说明.txt`](目录与使用说明.txt) 和 [`02_面试准备/03_现场代码练习说明.md`](02_面试准备/03_现场代码练习说明.md)。
